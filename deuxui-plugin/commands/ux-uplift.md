Run the deuxui `uplift` workflow on $ARGUMENTS.

Invoke the `deuxui` skill, then follow its `uplift` workflow
(`references/workflows/uplift.md`).

Derive the contract from the code that is already there before changing anything — that
is what puts the source of truth outside you, so a departure is measurable rather than
arguable. Default to preserve: being wrong about preserving costs a conservative variant,
being wrong about departing rewrites someone's product in a style they never asked for.

Fix in this order: UX defects, then the craft floor, then contract coherence.
