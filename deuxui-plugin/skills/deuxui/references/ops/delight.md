# delight — character at the moments that earn it

Delight is product character revealed through a useful interaction. It is not a
layer of whimsy applied evenly, and a celebration manufactured for an ordinary
click is worse than neutral clarity.

Derived from impeccable's `delight` (Apache-2.0) — see NOTICE.md.

## Where the opportunity actually is

Look for a moment that already carries feeling, and stop looking anywhere else:

- effort worth acknowledging — a long form completed, a migration finished;
- **waiting that could be informative** rather than blank (NUM-014: a pending
  status by 1s, a staged explanation by 10s — the honest version of this is also
  the delightful one);
- a first-run or empty state that could orient before it charms (UX-001);
- an error or recovery moment that needs empathy (UX-009);
- a capability people would enjoy discovering, which is still available to
  someone who never discovers it.

## One thesis, one sentence

State what the user should feel and why that feeling belongs to **this** product.
Then pick the smallest system that delivers it. Derive the treatment from the
product's own mechanism and visual world — a stock confetti burst is a
declaration that nobody looked for the product's own material.

## The constraints that make it safe

Delight must not delay, block or obscure the primary task; must not override a
platform convention or an accessibility behaviour; must not add a factual claim
nobody authorised; and must survive the hundredth repetition.

In an error state, lead with the problem and the recovery. Warmth can lower
stress. A joke must not trivialise lost work, money, privacy, or a blocked task —
that is `S-DARK-PATTERN` territory and it is a P0 family.

Visitor mode narrows this sharply: on an **operate** or **read** surface,
reliability carries the experience and delight is concentrated at first use,
completion, recovery and mastery. On **persuade** and **experience** surfaces
personality may run through voice, composition and motion, as long as the
artifact stays the focus.

## Verify

| Detector | What it settles |
|---|---|
| `S-SLOP-EMOJI` | Personality is not being outsourced to emoji in headings and buttons. |
| `S-CRAFT-VOICE` | The copy is the product's language, not generic warmth. |
| `S-MOTION-REDUCE` | The flourish has a reduced-motion path. |
| `S-STATE-PREMATURE` | No celebration fired before the work actually succeeded. |
| `S-DARK-PATTERN` | Nothing charming is manipulating anyone. |
| `R-STATE-EMPTY` | The empty state, forced: does it orient before it charms. |
