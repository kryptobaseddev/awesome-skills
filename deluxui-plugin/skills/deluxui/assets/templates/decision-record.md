# Decision record — DEC-<n>

For a design decision someone will later ask about. Short is fine; the point is that
the reasoning survives after the person who had it has moved on.

**Decision.** One sentence, in the present tense.

**Context.** What was true when this was decided — the constraint, the measurement, the
user problem.

**Applicable rules.** The rule IDs this engages.

**Options considered.** Each with the reason it lost. An option list with no rejected
options is a justification, not a decision.

**Trade-off accepted.** What got worse. Every real decision makes something worse; if
you cannot name it, the decision has not been examined.

**How it was verified.** Which detectors or manual checks, and the result.

**Revisit when.** The condition that should reopen this — a measurement, a scale
threshold, a platform change.
